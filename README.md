# Elimu Kenya

Independent proposal with supplied photos preserved, accessible payment availability screen and Render static-site packaging. No payments accepted. See DEPLOYMENT.md for deployment steps, optional Supabase draft schema and remaining live-service requirements.

Brand assets: assets/elimu-logo.svg; SVG, ICO and PNG favicons; Apple touch icon; 192px and 512px icons; site.webmanifest. Chrome may cache the previous favicon; after deploying, reload or close and reopen the tab. The manifest provides app metadata but this site has no offline service worker.

The red Elimu identity is retained in all icons. favicon.ico and a crawlable 48px PNG are linked from every page. Search engines choose whether and when to display a favicon; an icon does not indicate uptime or guarantee indexing.
